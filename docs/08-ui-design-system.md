# HomeHunt — UI Design System

## Current status
Foundation document. Visual tokens should be refined during the UI implementation sprints.

## Principles
- Responsive-first.
- Mobile usability is a first-class requirement.
- Prefer reusable components.
- Prefer shadcn/ui primitives before creating custom equivalents.
- Avoid duplicated component variants.
- Consistent spacing, typography, borders, radii, states and interaction patterns.

## Required states
Major components should account for:
- loading
- empty
- error
- disabled
- success
- mobile
- tablet
- desktop

## Design rule
Antigravity and other agents must not introduce unrelated visual systems without documenting the reason.
