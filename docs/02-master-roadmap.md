# HomeHunt — Master Roadmap

## Planning model
Two-week sprints are the default planning unit. Duration is a planning framework, not a fixed promise.

## Sprint completion rule
A sprint is complete only when its acceptance criteria are met, relevant tests pass, the application builds successfully, and the implementation has been reviewed.
