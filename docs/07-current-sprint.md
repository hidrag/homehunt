# HomeHunt — Current Sprint

## Sprint
S0 — Architecture & Project Foundation

## Status
[~] In progress

## Goal
Create the clean project foundation for the HomeHunt MERN application without implementing feature-domain logic prematurely.

## Current objectives
- Create repository structure.
- Set up client and server applications.
- Configure React/Vite/Tailwind/shadcn/ui.
- Configure Express.
- Connect MongoDB Atlas through Mongoose.
- Establish environment configuration.
- Establish linting/formatting.
- Establish routing and base layouts.
- Establish Redux Toolkit store structure.
- Establish backend middleware/error handling structure.
- Create documentation and architecture files.
- Establish Git workflow and initial CI foundation.

## Explicitly out of scope
- Full authentication implementation
- Property CRUD implementation
- Search/filter implementation
- Chat
- Visits
- Notifications
- Analytics
- PWA

## Acceptance criteria
- Client starts successfully.
- Server starts successfully.
- Health endpoint works.
- MongoDB connection works in configured environments.
- Client can reach server API.
- Base routes resolve.
- Lint/build succeed.
- No secrets are committed.
- Folder structure follows the architecture document.
